# Terminal log - Exercise 1

## `pwd`

Shows the folder you are in

## `ls`

lists all the files and folders inside your current directory.

## `cd ~/Documents`

It moves one out of the project folder and jumps straight into the computer's main Documents folder.

## `cd ..`

It moves one backward to the root folder.

## `cd ~`

It takes one to the root home folder.

# Terminal Log — Exercise 2

## 1. `mkdir my-project`

Created the main project directory.

## 2. `mkdir -p my-project/src/css my-project/src/js my-project/src/images`

Created the src directory and its nested css, js, and images directories.

## 3. `mkdir my-project/docs my-project/tests`

Created the docs and tests directories.

## 4. `touch my-project/README.md`

Created an empty README.md file inside my-project.

## 5. `find my-project`

Displayed the directory structure to verify that everything was created correctly.

## 6. `git clone URL`

Downloads a remote repository from GitHub to your computer.

## 7. `git log`

Displays detailed commit history.

## 8. `mkdir ~/git-practice`

Creates a folder called git-practice.
